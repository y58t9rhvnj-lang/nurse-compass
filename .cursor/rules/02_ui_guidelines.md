# UI Guidelines

Compass Version2.1 以降の UI / UX 原則。Learning Workspace としての体験を損なわないこと。

## 必須

- **iPad First** — 講義中の iPad Safari を最優先。タッチ・視認・スクロールを PC 前提で設計しない。
- **1パターン集中 UI** — 一度に考える健康パターンは一つ。11パターン同時入力の画面にしない。
- **Workspace 中心** — 患者を中心にした Workspace。様式や AI が主役にならない。
- **「患者理解の手がかり」を参照する** — 様式2等はコピー元ではなく参照手がかりとして見せる。
- **転記ボタンを作らない** — 様式2→様式3の自動転記・一括コピー UI は実装しない。
- **色は意味だけに使う** — 装飾色を増やさない。状態理解のための意味色のみ（正常/強み/問題/リスク/情報不足）。
- **保存を意識させない** — 明示保存ボタンに依存する流れを基本にしない。オートセーブ前提。
- **情報量より思考しやすさを優先する** — 一度に見せる量を減らし、考える余白を残す。

## 反例（やらない）

- ダッシュボード的な多パネル同時入力
- 「様式2からすべて転記」ボタン
- 保存しないと先に進めないフロー
