# Education Principles

Compass Version2.1 以降の教育思想。便利さより教育効果を優先する。

## 必須

- **Guide は答えを書かない** — 定義・視点・ヒントのみ。看護問題・解釈・正解の提示はしない。
- **Coach は問い返す** — 気付き・根拠・視点拡大の質問。学生の代わりに結論を出さない。
- **AI は正解を出さない** — 看護問題の決定、関連図の完成、模範解答の提示をしない。
- **学生が考える余白を残す** — 自動化・補完・転記で思考を奪わない。
- **Learning Workspace を維持する** — 記録完成ツール化・電子カルテ化の方向へ寄せない。
- **思考を深める UI を優先する** — 入力完了率より、再整理・再解釈・根拠付けができる体験。

## AI の役割（要約）

AI は「思考を代替する」存在ではない。  
視点を広げ、根拠を問い返し、見落としに気付かせるために存在する。

## 学校指定様式の遵守

Compass では、学校・養成校・実習施設が指定する様式を**最優先**とする。

- 項目名、入力順序、様式の構成、様式の意味は、Compass の都合で変更しない。
- Compass は様式を作り替えるシステムではない。
- Compass は「指定された様式で、より深く考えられるよう支援する Learning Workspace」である。

教育効果を高める改善は、次によって実現する（様式そのものは変更対象外）。

- ガイド
- 補助説明
- 考えるヒント
- UI
- Compass Coach
- 患者理解の導線

実装・提案では、「学校指定様式を変更する提案」ではなく、**「様式は維持したまま教育効果を高める提案」**を優先する。

学校指定様式は教育上の共通言語である。  
Compass はその共通言語を変更するのではなく、その共通言語を使って学生の患者理解を深めることを目的とする。

## 学習プロセスの尊重

Compass は完成した看護記録だけを評価対象としない。

- 途中の気付き
- 途中の修正
- 途中の迷い

も、患者理解を深める重要な学習過程である。

そのため、実装は学生が途中から安心して再開できることを前提とする（途中保存・途中修正・未完成の肯定）。
