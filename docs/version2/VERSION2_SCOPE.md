# VERSION2_SCOPE — Version2 スコープ定義（案）

> ステータス: **設計案（講義後フィードバックで確定）**。実装はまだ行わない。

## 1. Version2 の目的

Version2 は、学生が患者との面接や電子カルテから得た情報を **整理し・意味づけし・患者理解へつなげる** 学習プロセスを強化する。

Version1 の目的である
> 「学生が患者との面接を通して必要な情報を収集し、電子カルテと結び付けながら患者理解を深めること」

は **維持** する。Version2 は単なる機能追加ではなく、次の 6 段階の思考過程を支援することを目的とする。

1. 情報を **収集する**（面接・カルテ・観察）
2. 情報を **分類する**（種類・視点で仕分ける）
3. 情報同士を **関連づける**（点を線にする）
4. 重要な情報を **見極める**（優先度・意味の重み）
5. 患者の **全体像を言語化する**（自分の言葉で）
6. **看護上の課題へつなげる**（理解を看護へ）

### 教育上の芯（変えてはいけない前提）

- 新機能は **学生の思考を代行しない**。
- Compass Coach は答えを直接与えず、**問い返し**を基本とする。
- 情報整理ノートは答えを自動生成する場ではなく、学生が **自分の言葉で整理する場** とする。

## 2. 対象機能（Version2 で扱う候補）

| 学習段階 | 支援する機能（候補） | 既存スキャフォールドとの対応 |
| --- | --- | --- |
| ①収集 | 患者発言・カルテ・観察を「情報カード」として収集する | `collection` flag / `InformationCard` |
| ②分類 | 情報カードにカテゴリ/視点を付与し仕分ける | `InformationCard.category`（分類方式は保留） |
| ③関連づけ | 複数カードを束ねて「整理された情報」を作る | `OrganizedInformation.sourceDataIds` |
| ④見極め | 重要度づけ・並び替え | `reorderCards` / 重要度は保留 |
| ⑤言語化 | 患者の全体像を学生の言葉で記述する（改稿履歴あり） | `OrganizedInformation`（revision履歴） |
| ⑥看護課題 | 全体像から看護上の課題への橋渡し（問いベース） | Coach 連携（介入方式は保留） |

> いずれも feature flag（`informationNotebook` / `collection` ほか）で **off 既定**。段階的に有効化する。

## 3. 対象外機能（Version2 では扱わない）

- 学生アカウント / ログイン / 認証
- データベース / サーバー永続化 / クラウド同期
- 教員管理機能・クラス管理・成績管理（※「教員閲覧」は保留項目として検討のみ）
- スマートフォン最適化（主対象は iPad / PC）
- 患者データ・患者会話内容・Compass Coach 応答内容・看護記録・診療録・4帳票の変更
- 自動診断・自動アセスメント生成（＝学生の思考の代行）

## 4. Version1 との違い（差分の要点）

| 観点 | Version1（凍結） | Version2（案） |
| --- | --- | --- |
| 中心の学習行為 | 面接で情報を集め、カルテと結ぶ | 集めた情報を**整理・意味づけ・言語化**する |
| 情報カード | 型・保存基盤のみ（UI非接続） | 収集・分類・関連づけの**UIを解禁**（flag） |
| 情報整理ノート | 非表示（`informationNotebook: false`） | 学生が自分の言葉で整理する**作業空間を解禁**（flag） |
| Compass Coach | 面接中の問い・ヒント | 整理段階でも**問い返し**で伴走（介入方式は保留） |
| 導線 | 病棟→患者トップ→電子カルテ→気づきメモ | 上記＋**整理ワークスペース**への行き来 |
| 保存 | `localStorage`（会話・メモ・カード基盤） | `localStorage` を拡張（患者別・version付き） |
| feature flag | すべて off | 段階的に on（講義後判断） |

> Version1 の画面・データ・導線・URL は不変。Version2 は **加算的**に、flag で隔離して導入する。

## 5. 成功条件（Version2 のゴール指標・案）

学習面
- 学生が「集めた情報」を自分でカテゴリ分けし、関連づけられる。
- 学生が患者の全体像を **自分の言葉** で書ける（コピペ・自動生成に依存しない）。
- 全体像から看護上の課題へ、学生自身が **問いを立てて** つなげられる。

体験面
- iPad / PC で操作が破綻しない（タップ・スクロール・入力）。
- 面接・カルテ・整理ノートの **行き来が迷子にならない**。
- 保存が確実で、再訪時に **続きから** 学習できる。

安全面（回帰防止）
- Version1 の講義導線・表示・データが一切壊れない。
- feature flag off のとき、Version1 と完全に同じ挙動になる。

## 6. 非ゴール（明示）

- 「正解」を提示すること。
- 学生の代わりにアセスメントを完成させること。
- 進捗の点数化・評価・順位づけ（学習支援であり評価ツールではない）。
