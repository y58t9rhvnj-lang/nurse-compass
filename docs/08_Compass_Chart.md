# Compass Chart（精神科電子カルテ）

Version 1.1（設計書）
Sprint9

---

# 目的

実際の精神科病院で情報収集する流れを学ぶ。

Compass機能は補助であり、
電子カルテが主役。

---

## プロダクト上の位置づけ

Nurse Compass は Clinical Thinking Platform である（`00_Project_Charter.md` / `05_Thinking_Flow.md`）。

Compass Chart はその中の**教育用シミュレーション電子カルテ**であり、本物の業務システムの代替ではない。学生が「現場でどのように情報を探すか」を体験するための教材画面である。

Thinking Flow における情報優先順位では、電子カルテは④（患者 → 申し送り → プロフィールの後）。学生はまず Compass Patient で患者を見てから、必要に応じてカルテへ進む。

```
患者を見る（Compass Patient）
    ↓
違和感・疑問を持つ
    ↓
情報を探す（Compass Chart）← 本スプリント
    ↓
患者へ戻る
```

---

# 参考：Alpha 電子カルテから学ぶこと

添付スクリーンショット（診療支援システム Alpha）は**UI をコピーするためのものではない**。

参考にするのは以下のみ。

| 観点 | Alpha での特徴 | Compass Chart への落とし込み |
|------|---------------|---------------------------|
| 情報収集の流れ | 患者ヘッダーで文脈を固定 → 大項目タブで領域を選ぶ → サブ分類で絞る → 一覧 → 詳細 | 同じ階層構造を iPad 向けに簡素化 |
| 情報のグルーピング | 職種別記録（医師・看護・OT・PSW 等）、時系列（フローシート）、属性別（患者情報） | 職種は診療録内フィルタ、時系列はフローシート、属性は患者情報 |
| タブ構成 | カルテ / フローシート / 患者情報 が主軸 | Version1 は4画面に集約（下記） |
| 精神科導線 | 生活歴・隔離拘束・睡眠活動・GAF・生活技能訓練が主要機能として存在 | 生活歴を独立画面化。フローシートに睡眠・活動を含める |

Alpha の UI は情報密度が高く、タップ領域が小さい。Compass Chart では**同じ情報構造を、Design System と Apple HIG に沿った iPad 向けレイアウトで再設計**する。

# 画面構成

## 全体レイアウト

既存の 3 カラム構成を維持する（Apple HIG / Design System / Compass Patient と整合）。

```
┌──────────┬────────────────────────────────┬──────────────┐
│ SideNav  │  中央メイン（電子カルテ）        │  右ペイン      │
│          │                                │              │
│ 病棟ホーム │  患者サマリー（固定）            │  Compass     │
│ 患者トップ │  4画面タブ                     │  Notes       │
│ 電子カルテ │  ┌ 診療録                       │              │
│ …        │  │ フローシート                   │  Compass     │
│          │  │ 患者情報                       │  Coach       │
│          │  └ 生活歴                       │              │
│          │  画面固有コンテンツ               │              │
└──────────┴────────────────────────────────┴──────────────┘
```

- **SideNav**：現行と同様。`電子カルテ` をアクティブ表示。病棟ホーム・Compass Patient へ戻れる。
- **中央メイン**：電子カルテ本体。情報収集の主役領域。
- **右ペイン**：Compass 補助機能。カルテ閲覧中も思考を支援する。

遷移はクライアントのビュー状態方式（`AppShell` 上位管理）を継続する。Compass Patient の `CompassNav`「電子カルテ」導線、SideNav の「電子カルテ」から遷移する。

## 情報階層（Alpha 準拠 → iPad 再設計）

Alpha の情報収集は次の階層で進む。Compass Chart も同じ思考順序を維持する。

```
患者サマリー（文脈の固定）
    ↓
4画面タブ（大項目の選択）
    ↓
サブ分類（画面内フィルタ）
    ↓
一覧 / タイムライン
    ↓
詳細
    ↓
右ペイン（Compass Notes / Compass Coach）
```

### 患者サマリー（全画面共通・固定）

Alpha の青い患者ヘッダーに相当。画面上部に常時表示し、どのタブを見ても患者文脈を失わない。

| 項目 | 内容 | デザイン |
|------|------|---------|
| 氏名 | 大きめ表示（Compass Patient と同一患者） | Bold |
| 年齢・性別 | 補助テキスト | Small / Regular |
| 病室・入院状態 | 「309号室 / 入院中」 | 状態チップ |
| 現在地 | 病室・デイルーム等 | Design System 5状態カラー |
| 主治医 | 担当医名 | Small |
| 診断名 | 小さく補助表示 | 主役は人、診断は補助 |

「Compass Patient へ戻る」導線を左上に配置（`min-h-[44px]`、iPad タップ対応）。

GAF や「担当範囲」など Alpha 中段の臨床サマリーは、Version1 では**診療録タブ内のサマリーカード**に簡略化して配置する（全画面共通バーには載せない）。

## 4画面タブ（Version1 の主軸）

Alpha のトップタブ（カルテ / フローシート / 患者情報）と、精神科で重要な生活歴を、iPad 向けセグメントコントロールとして再構成する。

| タブ | Alpha 対応 | 学生が学ぶこと |
|------|-----------|--------------|
| **診療録** | カルテ → 診療録 | 職種横断の臨床記録を時系列で読む |
| **フローシート** | フローシート | 日々の状態・バイタル・行動を俯瞰する |
| **患者情報** | 患者情報 → 属性・基本 等 | 事務・連絡・入院歴など基盤情報を確認する |
| **生活歴** | 患者情報 → 生活歴 | 入院前の人生・背景を理解する |

- アクティブタブ：Primary Blue（`#0A84FF`）
- 非アクティブ：Warm Gray 背景、Regular テキスト
- タップ領域：最小 44px 高
- Alpha の「指示状況」「指示簿」「患者スケジュール」は Version2 以降

## Compass Chart への落とし込み

### レイアウト（iPad 横画面）

```
┌─────────────────────────────────────────────┐
│ 臨床サマリーカード（GAF・診断・担当範囲）      │
```

### 職種フィルタ（Alpha のドロップダウンに相当）

| フィルタ | 内容 |

| その他職種 | 栄養指導・生活技能訓練・集団精神療法 |

フィルタ UI は Alpha の密なドロップダウンではなく、**横スクロール可能なチップ列**（Design System の Chip）とする。

### 記録一覧

| 要素 | 仕様 |

| 選択状態 | 左アクセントバー（Blue）＋背景 `#F2F7FF` |
| 空状態 | 「この条件の記録はありません」 |

### 記録詳細

| 要素 | 仕様 |
|------|------|
| ヘッダー | 記録種別・診療科（精神科）・記録日時・記録者 |
| 本文 | Regular 本文。精神科記録らしい自然な文体 |
| 操作 | 読み取り専用（Version1） |

### 臨床サマリーカード

- GAF スコア（直近）

# ④ 生活歴

## Alpha から学ぶ構造

- 患者情報内の「生活歴」サブタブ
- 番号付きエントリの時系列リスト（[1] タイトル → 本文 → 最終更新日・記録者）
- 入院前の人生・家族・出来事など、精神科看護で特に重視するナラティブ情報
- 「新規登録」「並び替え」操作（Version1 では不要）

## Compass Chart への落とし込み

精神科電子カルテにおいて生活歴は独立した重要性を持つ。Alpha では患者情報のサブタブだが、Compass Chart では**トップレベルタブとして独立**させ、学生の情報収集導線を明確にする。

Compass Patient の `StoryCard`（これまでの歩み）との関係：

| 画面 | 役割 | 情報の性質 |
|------|------|-----------|
| Compass Patient / Story | 患者を「人」として理解する入口 | やさしく要約された物語 |
| Compass Chart / 生活歴 | カルテ上の公式記録としての生活歴 | 職種が記録した詳細なナラティブ |

学生は Compass Patient で概要を掴み、生活歴タブでカルテ原文を確認する、という二段階の学びを想定する。

### レイアウト

```
┌─────────────────────────────────────────────┐
│ 生活歴エントリ一覧（時系列・縦スクロール）     │
│  ┌ エントリカード [1] ──────────┐          │
│  │ タイトル                       │          │
│  │ 本文（複数段落可）              │          │
│  │ 最終更新日 / 記録者             │          │
│  └──────────────────────────────┘          │
│  ┌ エントリカード [2] ──────────┐          │
│  │ …                             │          │
│  └──────────────────────────────┘          │
└─────────────────────────────────────────────┘
```

### エントリ構造

| 要素 | 仕様 |
|------|------|
| 番号 | [1] [2] … 時系列順 |
| タイトル | エントリの主題（例：「ファイルメーカーからの生活歴」「3回目の入院」） |
| 本文 | 複数段落の自由記述 |
| メタデータ | 最終更新日・記録者名（右下、Small） |

一覧と詳細の分割は不要。カード自体が読み取り単位。長文はカード内スクロール。

# 右ペイン（全画面共通）

Compass Patient の右ペインと同一の役割・スタイルを継承する。

## Compass Notes

- Sprint7 で実装済みの気づきメモ（`NoteZone`）を右ペイン上部に配置
- カルテ閲覧中に気づいたことをその場で記録できる
- 患者別 `localStorage` 永続化（既存 `notesStore` を再利用）

## Compass Coach

- 濃紺背景・白文字・角丸カード（Design System）
- 患者別 `coachQuestions`（A・E・F は詳細、他はフォールバック）
- タブに応じた文脈の問いを表示（例：生活歴閲覧時 →「入院前の生活で気になる点は？」）
- 答えは表示しない。問いのみ
- 「この問いをメモする」導線で Compass Notes へ誘導（Sprint7 Priority B 継続）

# 学生の情報収集フロー（学習導線）

Version1 で想定する、精神科病院らしい情報収集の順序。

```
1. Compass Patient で患者を観察
       ↓
2. 電子カルテへ遷移
       ↓
3. 生活歴タブ → 入院前の背景を把握
       ↓
4. 患者情報タブ → 連絡先・入院歴を確認
       ↓
5. フローシートタブ → 直近の状態・睡眠・活動を俯瞰
       ↓
6. 診療録タブ → 職種別に記録を読む（医師→看護→OT/PSW）
       ↓
7. 右ペインの Notes / Coach で気づきを記録
       ↓
8. Compass Patient へ戻り、患者理解を深める
```

この順序は強制しない。学生が自由にタブを行き来できる。Coach の問いが自然な導線を示唆する。

# Version1で実装するもの

学生が情報収集できる**最低限の電子カルテ**。

## スコープ（Priority A）

| 区分 | 内容 |
|------|------|
| 画面 | Compass Chart 画面（中央メイン＋右ペイン）の新設 |
| 遷移 | Compass Patient / SideNav からの導線。`activeView` に `"chart"` を追加 |
| 患者サマリー | 全タブ共通の固定ヘッダー |
| 4画面タブ | 診療録 / フローシート / 患者情報 / 生活歴 |
| 診療録 | 職種フィルタ＋記録一覧＋記録詳細（Master-Detail）＋臨床サマリー |
| フローシート | サブタブ（全体/睡眠・活動/隔離・拘束）＋日別カード（直近7日） |
| 患者情報 | サブタブ（基本/連絡先/入院歴/治療歴）＋セクションカード |
| 生活歴 | 番号付きエントリカードの時系列一覧 |
| 右ペイン | Compass Notes ＋ Compass Coach（既存コンポーネント再利用） |
| データ | 受け持ち3名（A・E・F）を先行。他患者は最小限または空状態 |

## スコープ外（Version1 では実装しない）

- 記録の新規作成・編集・削除
- 指示簿・指示状況・患者スケジュール
- Alpha 左サイドバーの業務機能（オーダ送信・印刷等）
- バイタルグラフ（数値テーブルのみ）
- 全文検索・フィルタの高度化
- 他患者への一括データ投入
- バックエンド API 連携
- AI による要約・洞察

## データ方針

- `lib/chartData.ts`（仮）に4画面分の静的ダミーデータを定義
- 記録は精神科病棟らしい文体・内容（現実的だが個人が特定できない架空データ）
- 生活歴は Compass Patient の `story` と内容を呼応させつつ、カルテ原文としてより詳細に記述
- 医学的正確さより「学生が読んで情報収集の流れを学べるか」を優先

## デザイン方針

| 原則 | 適用 |
|------|------|
| Apple HIG | シンプル、余白、明確な階層、44px タップ領域、Master-Detail |
| Design System | Warm Gray 背景、白カード、16px 角丸、Line Icon、Very Soft Shadow |
| Compass Patient | 同一患者・同一色・同一ナビ構造。診断名は補助表示 |
| Thinking Flow | 情報量を増やさない。読むべき記録が自然に辿れる構成 |
| Alpha 非踏襲 | 色・フォント・グリッド密度・左サイドバーはコピーしない |

## 成功基準

学生が以下を体験できること。

1. Compass Patient で患者を見た後、電子カルテへ遷移できる
2. 生活歴で入院前の背景を読める
3. 患者情報で連絡先・入院歴を確認できる
4. フローシートで直近の睡眠・活動・バイタルを俯瞰できる
5. 診療録で職種別の記録を時系列で読める
6. 読みながら Compass Notes に気づきを残せる
7. Compass Coach の問いをきっかけに思考を深められる
8. Compass Patient へ戻り、カルテ情報と人物像を統合できる

# 既存画面との関係

```
病棟ホーム（ward）
    ↓ 患者タップ
Compass Patient（patient）
    ↓ 電子カルテ導線
Compass Chart（chart）  ← Sprint9
    ↓ Compass Patient へ戻る
Compass Patient（patient）
```

| 画面 | 主役 | Compass の役割 |
|------|------|----------------|
| 病棟ホーム | 病棟全体の状況把握 | 右ペインで患者選択 |
| Compass Patient | 患者を一人の人として理解 | Coach・Notes・各機能への導線 |
| **Compass Chart** | **電子カルテによる情報収集** | **右ペインで Notes・Coach が補助** |

| Compass Patient 要素 | Compass Chart 対応 |
|---------------------|-------------------|
| StoryCard（これまでの歩み） | 生活歴タブ（詳細原文） |
| PersonCard（人物像） | 患者情報タブ＋生活歴 |
| CompassToday（今日の様子） | フローシートタブ（直近の日別データ） |
| 診断名（下部補助） | 診療録タブの臨床サマリー |
