# Compass 利用案内（学生向け）

## Compass とは

Compass は、受け持ち患者「Aさん」と面接し、電子カルテを読み解きながら
**患者を一人の“人”として理解する**ことを練習する看護教育用の教材です。
病名を当てる演習ではありません。Aさんがどんな人で、何に困り、どんな思いで
入院生活を送っているかを、あなた自身が考えていきます。

## 推奨環境

- **推奨端末**: iPad（横向き推奨）または PC
  ※スマートフォンなど画面が狭い端末には対応していません。
- **推奨ブラウザ**: 最新版の Safari / Google Chrome / Microsoft Edge

## 使い方の流れ

1. **患者トップを開く**
   最初に「あなたの受け持ち患者（課題シート）」が表示されます。目標を読み、
   「Aさんのところへ行く」で面接を始めます。

2. **患者と面接する（患者会話）**
   画面の入力欄からAさんに話しかけます。挨拶から始め、表情・姿勢・視線の
   ヒントも参考にしながら、少しずつ話を聞いてみましょう。決まった正解を
   探すのではなく、相手の言葉に耳を傾けることが大切です。

3. **電子カルテを確認する**
   左メニューの「電子カルテ」から、診療録・看護記録・医療サマリー・処方・
   検査・指示・文書フォルダ（各種帳票）を確認できます。上部のタブで切り替えます。
   カルテだけで判断せず、本人の話と合わせて考えましょう。

4. **Compass Coach に相談する**
   迷ったときは Compass Coach が問いかけで考えを整理する手助けをします。
   答えを教えるものではありません。

5. **気づきメモを残す**
   観察したことや疑問に思ったことを「気づきメモ」に書き留めましょう。
   小さな気づきから始めて構いません。

## 保存についての注意

- 気づきメモなどの入力内容は、**あなたが使っている端末のブラウザ内にのみ**
  保存されます。サーバーには送信されず、他の学生とは共有されません。
- そのため、**別の端末・別のブラウザでは内容が引き継がれません。**

## 共有端末（実習室のPC・iPadなど）を使うとき

- 前の人のメモが残っている場合があります。
- **授業終了後は、自分の入力内容を消去してください。**
  - ブラウザの「サイトデータを削除」を行う、または
  - 担当教員の案内する初期化手順に従ってください。

## 授業終了後にすること

- 共有端末の場合は上記のとおりデータを消去する。
- 自分専用の端末の場合は、そのまま閉じて構いません（次回も内容が残ります）。

## うまく動かないとき

- まずページを再読み込みしてください。
- 画面が真っ白・エラー表示になった場合は「トップへ戻る」または再読み込みを試してください。
- 直らない場合は、使用端末・ブラウザ・状況を担当教員に伝えてください。

## 大切なお願い

本教材の患者・家族・職員・病院はすべて**架空**です。
実在患者の電子カルテではなく、実際の診断・治療に用いるものではありません。
学習の目的で安心してご利用ください。
