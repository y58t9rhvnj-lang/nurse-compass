# Compass Version1 公開前チェックリスト

Version1（v1.0.0）を学生向け本番環境へ公開する前に、以下を確認します。
各項目を確認したらチェックを入れてください。

## ビルド・品質

- [ ] `npm install` が成功する
- [ ] `npx tsc --noEmit`（TypeScript）エラーなし
- [ ] `npm run lint`（ESLint）エラーなし
- [ ] `npm run build`（本番ビルド）成功
- [ ] `npm run start`（本番起動）で起動する
- [ ] ランタイムエラー・Hydrationエラーがない
- [ ] ブラウザコンソールに致命的エラー・大量デバッグログがない

## 環境変数・セキュリティ

- [ ] 環境変数設定（本番で必須の環境変数は「なし」を確認）
- [ ] `.env.example` が最新である
- [ ] `.env` / `.env.local` が Git にコミットされていない（`.gitignore` 確認済み）
- [ ] APIキー・トークン・秘密鍵・接続情報がコードに含まれていない

## 症例・個人情報

- [ ] Patient A を含む全症例が架空である
- [ ] 患者名・生年月日・住所・電話・患者ID が架空である
- [ ] 病院名・医師名・看護師名・家族名が架空である
- [ ] 文書・署名欄・画像ファイル名・コメント・ログに実在情報がない

## 画面確認（PC）

- [ ] トップ（病棟ホーム）
- [ ] 患者トップ（受け持ち患者・課題シート）
- [ ] 患者会話
- [ ] Compass Coach
- [ ] 診療録（SOAP・看護記録の参照表示）
- [ ] 看護記録（記録／看護計画／看護サマリー）
- [ ] 医療サマリー
- [ ] 処方・検査・指示
- [ ] 文書フォルダ・PDF（風）表示
- [ ] Version1 講義導線
- [ ] Stickyタブに内容が隠れない
- [ ] 意図しない横スクロールがない

## 画面確認（iPad 横／縦）

- [ ] 主要画面が表示・操作できる
- [ ] タップ位置がずれない・文字が極端に小さくない
- [ ] 横スクロールが発生しない
- [ ] Stickyタブに帳票上部が隠れない
- [ ] PDF（風）帳票が閲覧・戻る操作できる

## データ・エラー処理

- [ ] localStorage に学生ごとに端末内保存される（他学生と共有されない）
- [ ] ページ更新後もメモが残る
- [ ] 学生データの初期化手段が案内されている（サイトデータ削除／スニペット）
- [ ] 存在しないURLで日本語の 404 画面が出る（`app/not-found.tsx`）
- [ ] 予期しないエラー時に日本語のエラー画面が出る（`app/error.tsx`）
- [ ] ブラウザバックで操作不能にならない

## 公開

- [ ] 公開URLの確認（未確定の場合はプレースホルダー）
- [ ] 学生向け利用案内の確認（`docs/STUDENT_GUIDE.md`）
- [ ] Version1 タグ（v1.0.0）確認
- [ ] `package.json` の version が `1.0.0`
