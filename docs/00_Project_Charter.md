# Nurse Compass Project Charter

Version 1.0
Last Update: 2026-07-09

---

# Mission

知識を覚えるのではなく、
患者を理解する思考を育てる。

---

# Vision

すべての看護学生が、
患者を一人の人として理解し、
自ら考え、判断し、行動できる世界をつくる。

---

# Product Definition

Nurse Compassは電子カルテ教材ではない。

患者理解と臨床推論を学ぶための
Clinical Thinking Platformである。

---

# Target Users

・看護学生
・新人看護師
・実習指導者
・看護教員
・病院教育担当者

---

# Educational Goal

学生が

・患者を観察できる

・疑問を持てる

・情報を探せる

・仮説を立てられる

・アセスメントできる

ようになることを目標とする。

---

# Core Principles

① Patient First

患者は診断名ではなく、
一人の人として理解する。

② Thinking First

答えではなく、
考える過程を大切にする。

③ Reality First

精神科病棟の現場を忠実に再現する。

④ Learning by Doing

読むのではなく、
体験して学ぶ。

⑤ AI as Coach

AIは答えを教えない。

考えるきっかけを与える。

---

# Product Values

・Simple
・Beautiful
・Educational
・Clinical
・Trustworthy

---

# Success Criteria

Version1.0の成功とは

学生が

「患者を理解する思考」

を身につけることである。

機能数では評価しない。

教育効果で評価する。

# Long Term Vision

Nurse Compassを

看護学校

病院

新人教育

看護管理教育

で利用される教育プラットフォームへ成長させる。
