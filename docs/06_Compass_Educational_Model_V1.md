## 0. Educational Model Freeze 宣言

本書は、Version1 の教育モデルを実装の基盤として**凍結（Freeze）**する。

「Freeze」は「二度と変更できない」という意味ではない。次を意味する：

- 実装は本ベースラインに従う。
- モデルの変更には、`docs/09_Design_Log.md` への**記録された設計判断**が必要である。
- 学生・教員からのエビデンスは、改訂の根拠となりうる。
- **利便性だけでは**モデルを変更する理由にならない。

## 1. North Star（北極星）

```
Compassは、患者を理解するための思考を支え、
その思考の積み重ねによって看護過程が自然に完成する学習環境である。
```

あわせて、次を掲げる：

```
考えを導いた結果、様式が完成する。
Compassは、書く時間を減らし、考える時間を増やす。
```

---

## 2. What Compass is / is not

### Compass は次のものである

- 患者理解のための学習環境
- 臨床思考のワークスペース（Clinical Thinking Workspace）
- 学生の思考過程（reasoning process）を保持するシステム
- 転記（transcription）を減らすが、思考は減らさないシステム

### Compass は次のものではない

- 記録を完成させるためのシステム（documentation-completion system）ではない
- アセスメントの自動生成器ではない
- 看護問題の自動生成器ではない
- 学生の代わりに考える AI ではない
- 様式を速く埋めることを目的とするシステムではない

---

## 3. Educational Flow（学習の流れ）

```
患者との対話・観察・カルテ
   ↓
気づき（Noticing）
   ↓
一時メモ（Temporary memo）
   ↓
収集（Collection）
   ↓
収集データ（Collected data）
   ↓
患者理解の視点（Patient-understanding perspectives）
   ↓
情報（Information）
   ↓
比較・「あれ？」（Comparison / “あれ？”）
   ↓
手がかり（Cue）
   ↓
様式2（Form 2）
   ↓
様式3（Form 3）
   ↓
病態関連図の参照（Pathophysiology reference）
   ↓
患者関連図（Patient relationship diagram）
   ↓
看護問題がなぜ生じているかの理解
```

各段階の教育的役割：

| 段階 | 教育的役割 |
|------|------------|
| 患者との対話・観察・カルテ | 事実（データ）が生まれる出所。学生はまず患者と向き合う。 |
| 気づき（Noticing） | 興味・違和感・矛盾・疑問が生まれる瞬間。思考の起点。 |
| 一時メモ（Temporary memo） | 思考を中断させないための自由な作業領域。まだ収集データではない。 |
| 収集（Collection） | 「患者理解のために残す価値がある」と学生が判断してデータを保存する行為。 |
| 収集データ（Collected data） | 出所と原文を保持した事実。編集して意味づけしない。 |
| 患者理解の視点 | データを整理する切り口（テーマ）。学生が選び、変更・追加できる。 |
| 情報（Information） | データを視点別に整理し、S/O/未分類へ分類したまとまり。解釈文を含まない。 |
| 比較・「あれ？」 | 情報を見比べ、ズレ・つながり・違和感に気づく思考。 |
| 手がかり（Cue） | 情報を根拠に学生が考えた解釈・関連・追加確認・看護問題の方向性。 |
| 様式2 | 患者の全体像を初期的につかむ表現。完成アセスメントではない。 |
| 様式3 | 方向性に沿って深めるための情報収集・整理の表現。 |
| 病態関連図の参照 | 一般病態の参照（教育者が用意）。個別解釈は含まない。 |
| 患者関連図 | 一般病態と個別患者を、学生自身が接続して表現する。 |
| 看護問題がなぜ生じているかの理解 | Version1 の学習ゴール。学生自身の言葉で説明できる状態。 |

## 4. Five Levels of Thinking（思考の5段階）

1. **気づき（Noticing）**
   興味・違和感・矛盾・好奇心が生まれる瞬間。

2. **一時メモ（Temporary memo）**
   思考を中断させないための、構造化されていない置き場。
   まだ「残す」と決めていない、途中の考え。

3. **収集（Collection）**
   患者理解のために「残す価値がある」と学生が判断すること。

4. **情報（Information）**
   収集データを患者理解の視点で整理し、S / O / 未分類に分類したもの。

5. **手がかり（Cue）**
   学生の解釈・関連・追加確認の方向性・看護問題の可能性の方向。

> 様式（Forms）は、これら思考段階の**後に生まれる出力（output）**である。
> 様式は思考の出発点ではない。

---

## 5. Data / Information / Cue（精密な定義）

### Data（データ）

- 編集していない事実
- 患者の発言
- 観察
- カルテ記載
- 測定値
- **出所（source）と原文（original wording）を保持する**

### Information（情報）

- 1つ以上の収集データを、患者理解の視点で整理したまとまり
- subjective / objective / unclassified に分類される
- **解釈文（interpretation sentences）を含まない**
- 1つのデータは複数の視点に属してよい

### Cue（手がかり）

- 学生が作成する解釈、または思考の方向
- **根拠（evidence references）を必ず保持する**
- 確定した看護問題ではない
- Compass が自動生成しない

---

## 6. Temporary Memo（一時メモ）

右側のメモ（気づきメモ）を、次のように定義する：

- 作業記憶（working memory）の場
- 未完成の考えの置き場
- 疑問・備忘・観察・粗い言葉のための場
- **自動的に収集データとして扱われない**
- 何を収集するかは、学生が**明示的に**選ぶ
- 自由に編集・削除してよい

---

## 7. Unified Collection Model（統一収集モデル）

収集を、教育的な行為として定義する：

```
収集とは、患者理解のために残す価値があると学生が判断したデータを保存する行為である。
```

すべての出所が、同じ「収集」の概念を用いる：

- 患者との会話
- 診療録
- 看護記録
- フローシート
- 処方
- 検査
- 生活歴
- OT（作業療法）
- PSW
- 学生の観察
- 一時メモ

収集は次を支える：

- 必要な内容を選ぶ
- 保存された文言を確認する
- 原文を保持する
- 出所・時刻・ナビゲーション参照を保持する
- 保存された**表示内容**は後から修正できる（原文は保持したまま）
- **収集解除**を、元の出所を削除せずに行える

---

## 8. Role of AI / Coach（AI・Coach の役割）

Compass Coach は次を行ってよい：

- 問いを投げかける
- 視点を広げる
- 比較を促す
- 根拠を尋ねる
- 未完了の重要テーマを学生に思い出させる
- 学生が求めたとき、または行き詰まったときにのみ介入する

Compass Coach は次を行ってはならない：

- データを自動分類する
- 情報グループを自動作成する
- 手がかりを生成する
- 解釈文を書く
- アセスメントを完成させる
- 看護問題を決定する
- 自然に進行している会話を中断する

---

## 9. Forms（様式）

- 様式2・様式3・関連図は、出発点ではない。
- それらは、**完了した思考の表現（expression）**である。
- 学生は、整理済みの情報を引用してよい。
- 学生は、直接入力してもよい。
- 繰り返しの転記は減らすべきである。
- ただし、解釈の判断は依然として学生が行わなければならない。

---

## 10. Educational Hypothesis（教育仮説）

本モデルは、Version1 の**教育仮説**である。
実装後に、学生・教員とともに次を評価しなければならない：

- 用語の分かりやすさ
- 教育上の有用性
- 実際のワークフローとの適合
- S/O 分類が学習を助けるか
- 「データ／情報／手がかり」が自然に理解されるか
- 思考が増えるか
- 不要な書き込みが減るか
- 様式が思考から自然に生まれるか

評価の結果、名称・区分・操作は見直しうる（変更は `docs/09_Design_Log.md` に記録する）。
